functions THERMALX — Mathematical Formulation

1. Governing 2D Heat Diffusion Equation:

k ∇² T + Q(x,y) - h_conv (T - T_amb) = 0

2. 5-Point Finite Difference Stencil:

T_(i,j)^(k+1) = [ T_(i+1,j) + T_(i-1,j) + T_(i,j+1) + T_(i,j-1) + (h²/k)*Q_(i,j) + H*T_amb ] / (4 + H)

Where H = h_conv * h² / k represents dimensionless cooling convection.

3. Jacobi vs Gauss-Seidel:

Jacobi: Calculates T^(k+1) exclusively from the previous grid T^k without reusing newly calculated values.

Gauss-Seidel: Reuses T_(i-1,j)^(k+1) and T_(i,j-1)^(k+1) immediately in the current iteration scan, accelerating convergence roughly by a factor of 2.

4. Convergence Stopping Criterion:

L_∞ Error = max | T_(i,j)^(k+1) - T_(i,j)^(k) | ≤ Tolerance (0.001)

schema LINKRANK — Mathematical Chain

1. Adjacency Matrix A:

A_(j,i) = 1 if a directed link exists from node i → node j, otherwise 0.

2. Column-Stochastic Transition Matrix M:

M_(j,i) = A_(j,i) / OutDegree(i), ensuring each column sums to 1.0 (conserving probability mass).

3. Google Matrix with Damping (d = 0.85):

G = d * M + (1 - d) / N * J_(N×N)

Guarantees primitivity and positive column sum via the Perron-Frobenius Theorem.

4. Dominant Eigenvector Power Iteration:

v^(k+1) = G * v^k, converging to the stationary distribution where λ₁ = 1.000.
